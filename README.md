# Sarva Kalyana Seva — Task 15 Final React Project

**Tagline:** From Celebration to Contribution — Feeding Hope. Sharing Humanity.

## Included Task 15 concepts
- React components and reusable props
- React Router DOM
- Nested routing (`/services/:slug`)
- `useParams`
- `useSearchParams`
- `useState`
- `useEffect`
- `useRef`
- `useContext`
- `useReducer`
- Conditional rendering
- List rendering
- Axios API integration through `useFetchData`
- Custom hook
- Redux Toolkit
- CRUD demo for programs/events
- Form validation
- Responsive UI
- Dark/light theme
- Local organization posters and branding
- Instagram connection

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
