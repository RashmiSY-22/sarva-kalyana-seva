# Final submission checklist

1. Extract this folder.
2. Open it in VS Code.
3. Run `npm install`.
4. Run `npm run dev` and test all navigation links.
5. Run `npm run build`.
6. Create/push your GitHub repository.
7. Import the GitHub repository into Netlify.
8. Netlify build command: `npm run build`
9. Netlify publish directory: `dist`
10. Submit only the Netlify deployed domain.

The three supplied Sarva Kalyana Seva posters are stored in `public/assets/`:
- feeding-hope.png

- kalaprerna.png
